# abysse8

I build embedded systems, automation tools, and applied AI workflows that connect
real hardware to usable software.

## Selected Projects

- [ESP32 Display Panel](https://github.com/abysse8/esp32-display-panel): unified
  ESP32 firmware and RS485 protocol lab for Lumiplan, Mobitec, and Hanover-style
  destination displays.
- [ESP8266 Soil Node](https://github.com/abysse8/esp8266-soil-node): end-to-end
  grow-room telemetry stack with MQTT, Node/Express, SQLite, and a React
  dashboard.
- [Growroom Camera](https://github.com/abysse8/growroom-cam): ESP32 camera
  firmware with hardware docs for a two-servo pan/tilt head.
- [CoverGemini](https://github.com/abysse8/CoverGemini): mobile-to-cloud AI
  pipeline for generating tailored LaTeX CV PDFs from job posts.
- [LODeNNS](https://github.com/abysse8/LODeNNS): neuromorphic STDP nearest-neighbor
  research project from ICONS 2022.

## Focus Areas

Embedded C++ / PlatformIO, ESP32/ESP8266, RS485 protocol exploration, Python
automation, MQTT, React dashboards, Flask services, LaTeX document generation,
and applied machine-learning experiments.
